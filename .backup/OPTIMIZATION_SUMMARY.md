## 📊 问题诊断

### 表面症状
1. ✗ 不会判断趋势，下降趋势中一直抄底
2. ✗ 频繁开仓，几乎每次都交易
3. ✗ 止盈止损太远，短线交易触发不了

### 🎯 根本原因（深度分析）

#### 原因1: 数据周期选择错误
```
旧版：3分钟K线 + RSI7
问题：21分钟的数据周期无法判断趋势，只能捕捉噪音
类比：用显微镜看森林，只看到树叶抖动

新版：15分钟K线 + RSI14
改进：3.5小时的数据周期，能够反映短期趋势
```

**技术细节**:
- 3分钟K线：超短线数据，噪音极大，适合超高频交易（非本系统目标）
- 15分钟K线：短线交易黄金周期，过滤噪音但保留灵敏度
- RSI7 (3min) = 21分钟数据 → RSI14 (15min) = 3.5小时数据

#### 原因2: 指标周期过短
```
旧版：RSI7 + 3分钟K线 = 21分钟RSI
新版：RSI14 + 15分钟K线 = 3.5小时RSI（行业标准）
```

**为什么RSI14是标准**:
- RSI14是技术分析行业标准（Welles Wilder 1978年发明时的推荐周期）
- RSI7太敏感，容易产生假信号
- RSI14平衡了灵敏度和准确性

#### 原因3: Prompt没有教AI"看大图"

**旧版问题**:
```
AI看到的数据：
- 3分钟价格、EMA、MACD、RSI  ← AI主要关注这个
- 4小时EMA20/50、ATR        ← 只是"附加信息"

AI不知道：
- 应该先看4小时判断大趋势
- 再用15分钟找入场点
- 如果4小时是下跌，就不应该开多
```

**新版改进**:
```
明确的决策流程：
1. Step 1: 判断4小时趋势（多头/空头/震荡）
2. Step 2: 如果趋势明确，用15分钟找入场点
3. Step 3: 计算信号质量评分（>75分才开仓）
4. Step 4: 设置动态止损（基于ATR）
```

### 2️⃣ Prompt系统性重写 (decision/engine.go)

#### 核心理念（全新）
```
🎯 交易黄金法则：看大图 → 找入场点 → 耐心持有

1. 永远先看4小时趋势，再看15分钟入场点
2. 只做确定性高的交易（信号质量>75分）
3. 趋势是朋友，震荡是敌人
4. 耐心持有，减少频繁交易
```

#### 趋势判断标准（全新）
```
🟢 多头趋势（可做多）：
✓ 4h EMA20 > 4h EMA50 且扩大
✓ 4h MACD > 0 或金叉
✓ 4h RSI14 在45-70之间
✓ 价格在4h EMA20上方

🔴 空头趋势（可做空）：
✓ 4h EMA20 < 4h EMA50 且扩大
✓ 4h MACD < 0 或死叉
✓ 4h RSI14 在30-55之间
✓ 价格在4h EMA20下方

⚠️ 震荡市（观望）：
✗ 4h EMA20和EMA50距离<1%
✗ MACD在0轴震荡
✗ 价格反复穿越EMA20
```

#### 信号质量评分系统（全新）
```
评分规则（满分100分）：
- 4小时趋势明确：+30分
- 15分钟价格突破/跌破EMA20：+20分
- 15分钟MACD方向一致：+20分
- 15分钟RSI14在健康区间：+15分
- 4小时成交量增加：+10分
- 1h和4h价格变化同向：+5分

评分标准：
- 85-100分：优质信号
- 75-84分：一般信号
- <75分：观望！
```

#### 多重确认机制（全新）
```
做多信号（必须满足至少4/5个条件）：
1. ✓ 4小时多头趋势确立
2. ✓ 15分钟价格突破EMA20且EMA20向上
3. ✓ 15分钟MACD金叉或MACD>0且上升
4. ✓ 15分钟RSI14在40-70之间
5. ✓ 4小时成交量增加

做空信号（必须满足至少4/5个条件）：
1. ✓ 4小时空头趋势确立
2. ✓ 15分钟价格跌破EMA20且EMA20向下
3. ✓ 15分钟MACD死叉或MACD<0且下降
4. ✓ 15分钟RSI14在30-60之间
5. ✓ 4小时成交量增加
```

#### 动态止损（全新）
```
旧版：固定价格止损（如：92000, 98000）
问题：不考虑币种波动性，容易被扫或太远

新版：基于ATR动态调整
- 山寨币：止损 = 入场价 ± (4h ATR14 × 2)
- BTC/ETH：止损 = 入场价 ± (4h ATR14 × 1.5)
- 确保止损至少3-5%

止盈：止盈距离 = 止损距离 × 2.5（风险回报比2.5:1）
```

#### 交易频率控制（全新）
```
最小持仓时间：开仓后至少持有45分钟（3个周期）
开仓冷却期：平仓后至少观望30分钟再开新仓

例外情况（允许提前平仓）：
- 触发止损
- 4小时趋势反转
- 保证金使用率>85%
```

#### 决策流程重构（全新）
```
旧版：
1. 检查夏普比率
2. 评估持仓
3. 寻找机会
4. 执行决策

新版（5步详细流程）：
1. 分析夏普比率（调整风险偏好）
2. 判断市场环境（多头/空头/震荡）
3. 评估现有持仓（4h趋势是否仍有效）
4. 筛选新机会（先判4h趋势，再算质量评分）
5. 执行决策（写明趋势判断、信号、评分）
```

## 🎓 交易理念核心理解

### 为什么15分钟而不是3分钟？

**市场周期理论**:
```
微观噪音 (1-5分钟)：随机波动，无规律
短期波动 (15分钟-1小时)：技术性波动，可交易
中期趋势 (4小时-日线)：主力资金方向，核心趋势
长期趋势 (周线-月线)：宏观牛熊，基本面驱动
```

**本系统定位**: 短线交易（持仓几小时到一天）
- 用4小时判断中期趋势（战略方向）
- 用15分钟找入场点（战术时机）
- 不用3分钟（噪音太大）

### 为什么强调"看大图"？

**道氏理论核心**:
> "趋势有三：主要趋势、次级趋势、日常波动。  
> 只有顺应主要趋势，才能持续盈利。"

**实践案例**:
```
场景：4小时下跌趋势，15分钟RSI超卖

错误做法（旧版）：
- 看到RSI<30，立即做多抄底
- 结果：下跌趋势持续，连续止损

正确做法（新版）：
- 看到4小时下跌趋势，拒绝做多
- 等待15分钟反弹到RSI 50-60，做空
- 结果：顺势而为，高胜率
```

### 为什么需要多重确认？

**单一指标的陷阱**:
- RSI超卖：可能继续跌到更超卖
- MACD金叉：可能是假突破
- 价格突破：可能是主力诱多

**多重确认的优势**:
```
同时满足4-5个条件 → 假信号概率降低

数学原理：
- 单个指标准确率70% → 实际胜率40%（假信号多）
- 5个指标同时满足 → 实际胜率60-70%
```

## ⚠️ 注意事项

### 1. 需要适应期
新系统交易频率大幅降低，前几天可能觉得"不够活跃"，这是正常的。记住：**质量>数量**。

### 2. 观望也是一种决策
如果信号质量不够，AI会选择观望（wait）。这不是系统故障，而是风控！

### 3. 止损会触发
动态止损更合理，但仍会触发。重要的是：胜率提高后，盈利能覆盖止损。

### 4. 做空可能不习惯
如果看到AI做空，不要惊讶。下跌趋势中做空是正确的，这正是我们要修正的问题。
